# AdaL

**The coding agent with two modes.**

- `adal` — AdaL as a worker. It codes, plans, researches and browses with you like any coding agent, and asks before it changes anything.
- `adal --mode engineer` — AdaL as the lead engineer. Give it a goal and success criteria; it spins up Claude Code, Codex, AdaL and browser workers, coordinates them, evaluates the work with a separate evaluator, and drives the task end to end to a verified PR. Memory persists across projects and machines; skills self-evolve.

```bash
curl -fsSL https://adal.sylph.ai/install.sh | bash
adal
```

## Open source here

- [AdalFlow](https://github.com/SylphAI-Inc/AdalFlow) — Python library for agents, memory and tools (MIT). The backend's foundation.
- [atskills](https://github.com/SylphAI-Inc/atskills) — the @skills protocol: use any public `SKILL.md` for one task without installing it. Hub: [atskills.one](https://atskills.one).
- [adal-cli](https://github.com/SylphAI-Inc/adal-cli) — CLI docs and issues.
